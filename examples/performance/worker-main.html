Worker/OffscreenCanvas 渲染原型 worker-main

优先在 Web Worker 内用 OffscreenCanvas 渲染（n=5000，确定性全不透明组件树）， 帧经 transferToImageBitmap 送到主线程 ImageBitmapRenderingContext 展示。 兼容性处理：若环境不支持 Worker / OffscreenCanvas / ImageBitmapRenderingContext（或 worker 启动失败），自动回退到主线程渲染 并如实上报后端。可传 ?backend=main 强制走主线程路径（用于测试回退）。 结果写入 window.__workerBenchResult。详见 docs/architecture/10-worker-offscreen.md。
